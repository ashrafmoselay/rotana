# روتانا — Laravel لإدارة الأسطول والمشتريات

تطبيق فعلي بـ Laravel 12، واجهة عربية RTL مبنية على تصميم النسخة السابقة، وطلبات AJAX مرتبطة بقاعدة البيانات. الأصول الأمامية محلية؛ لا يحتاج npm أو CDN لتشغيل الواجهة.

## المتطلبات

- PHP 8.2+ (اختبر المشروع على PHP 8.3)، Composer 2.
- MySQL 8 أو MariaDB متوافق مع Laravel؛ ويمكن استخدام SQLite للتجربة والاختبارات.
- إضافات PHP: PDO وقائد قاعدة البيانات، BCMath، Ctype، cURL، DOM، Exif، Fileinfo، GD، Mbstring، OpenSSL، Tokenizer، XML، ZIP.
- جذر خادم الويب هو `public/` فقط. أعط مستخدم PHP حق الكتابة إلى `storage/` و`bootstrap/cache/`.

## تشغيل نسخة تجريبية

```bash
composer install
cp .env.example .env
php artisan key:generate
```

أنشئ قاعدة MySQL فارغة باسم `rotana` واضبط `DB_*` في `.env`. عيّن `DEMO_PASSWORD` بكلمة مرور تختارها لا تقل عن 12 حرفًا، ثم:

```bash
php artisan migrate --seed
php artisan serve
```

افتح `http://127.0.0.1:8000`. البريد الإداري `admin@rotana.test`، وكلمة المرور هي القيمة التي حددتها في `DEMO_PASSWORD`.

للتجربة بـ SQLite: أنشئ ملف `database/database.sqlite`، واضبط `DB_CONNECTION=sqlite` واحذف `DB_DATABASE` من `.env`، ثم نفّذ أوامر الترحيل السابقة.

| الحساب التجريبي | الوظيفة |
|---|---|
| admin@rotana.test | مدير النظام، جميع الفروع والصلاحيات |
| employee@rotana.test | موظف: إنشاء وتعديل وإرسال الطلبات |
| accountant@rotana.test | المحاسبة، الفواتير والمطابقة |
| manager@rotana.test | اعتماد مدير الإدارة |
| supervisor@rotana.test | اعتماد المشرف |
| treasurer@rotana.test | إثبات التحويل والإغلاق |
| warehouse@rotana.test | استلام ومخزون وصرف وتحويل ومرتجع وجرد |
| maintenance@rotana.test | كروت صيانة وطلبات مرتبطة |
| auditor@rotana.test | تقارير ومراجعة النشاط |

كل حسابات التجربة تستخدم `DEMO_PASSWORD`. حسابات التشغيل مقيّدة بفرع الرياض، والمدير والمراجع بجميع الفروع. لا تستخدم حسابات التجربة في الإنتاج. إعادة تشغيل Seeder تتخطى بيانات التجربة الموجودة؛ إعادة تأسيس الأدوار تعيد صلاحيات الأدوار الافتراضية. لا تستخدم `migrate:fresh` على قاعدة بها بيانات مهمة.

## ما تم تنفيذه

- Bootstrap RTL، jQuery، Select2 داخل Bootstrap Modal، Font Awesome، SweetAlert2، Toastr وApexCharts.
- DataTables بمعالجة خادمية وبحث وترقيم صفحات؛ فلاتر تاريخ وفرع وسيارة ونوع وحالة للطلبات والتقارير.
- السيارات، الموردون، الأصناف، المناطق، الفروع، مراكز التكلفة والمخازن: إضافة وتعديل وتعطيل. اختيار سجل قائم أو تسجيل جديد من نموذج الطلب.
- طلبات صيانة، تلفيات، قطع غيار، مرافق، فروع، تزويد مخزون وعروض أسعار. ربط كارت الصيانة بالطلب.
- دورة: مسودة ← محاسب ← مدير ← مشرف ← استلام ومطابقة ← جاهز للتحويل ← مدفوع ← مغلق، مع إعادة للتعديل ورفض قبل الاستلام.
- حساب المال بالهللات والكميات بأجزاء الألف، مع BCMath وتقريب نصف لأعلى. الإجمالي الأقصى 999,999,999 ريال.
- المطابقة تمنع التحويل حتى تتطابق كميات الطلب والاستلام والفاتورة والقيمة، مع مستند فاتورة وإثبات حوالة. سجل واحد للدفع لكل طلب ومرجع تحويل فريد.
- تعديل استلام المخزون يحتسب الفرق فقط. الصرف لا يسمح برصيد سالب، والمرتجع لا يتجاوز المصروف المتبقي، والتحويل يحافظ على إجمالي المخزون. الجرد يسجل فرق العدد الفعلي مع السبب.
- Spatie Permission للأدوار والصلاحيات، Spatie Activitylog للنشاط، وSpatie Media Library للمرفقات الخاصة.
- رفع ملفات أو التقاط صور من الهاتف عبر `capture=environment` حسب دعم الجهاز. تسع زوايا للسيارة قبل الإرسال، وصور بعد الإصلاح في مرحلة الاستلام والمطابقة. اختيار الكاميرا قد يختلف حسب المتصفح.
- تصدير الطلبات المفلترة والسيارات والموردين والأصناف إلى XLSX، وقوالب واستيراد الكيانات الثلاثة الأخيرة. الاستيراد يتراجع بالكامل عند خطأ أي صف. التصدير يخزن النصوص كنص لمنع تشغيلها كصيغ Excel.
- بيانات تجريبية لجميع مراحل الطلب وكروت الصيانة، ولجميع أنواع الطلبات، وتشمل فروقات فاتورة وحركات مخزون ومرفقات وصور.

## التشغيل الإنتاجي

على قاعدة جديدة، اضبط `APP_ENV=production` و`APP_DEBUG=false` و`APP_URL=https://your-domain` و`SESSION_SECURE_COOKIE=true`، واحذف `DEMO_PASSWORD`. لا تنقل `.env` التجربة أو قاعدة التجربة للإنتاج.

```bash
composer install --no-dev --optimize-autoloader
php artisan key:generate
php artisan migrate --force
php artisan rotana:create-admin
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

أمر إنشاء المدير يطلب الاسم والبريد وكلمة المرور تفاعليًا ويجهز الأدوار. استخدم إدارة البيانات لإضافة المناطق والفروع وبقية الإعدادات. صلاحيتا `users.manage` و`roles.manage` إداريتان مرتفعتان لأنهما تسمحان بمنح أدوار وصلاحيات؛ امنحهما لمدير موثوق فقط.

### تحديث نسخة إنتاج قائمة

ارفع الملفات إلى مسار التطبيق الذي يخدمه الموقع فعليًا، بما فيها `public/assets` و`resources/views` و`routes` و`app`. حافظ على ملف `.env` وملفات المستخدمين الموجودة. ثم نفّذ من مجلد التطبيق:

```bash
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

لا تحتاج تحديثات نسخة قائمة إلى إعادة توليد مفتاح التطبيق أو تشغيل seeders. ملفات الواجهة الخاصة بالتطبيق تحمل بصمة محتواها في الرابط لتحديث كاش المتصفح عند تغييرها. بعد النشر أعد تحميل الصفحة؛ إذا كان CDN يخزن الصفحة أو يتجاهل معاملات الرابط، امسح الكاش الخاص بالموقع أيضًا. إذا كان PHP OPcache لا يتحقق من تغيّر الملفات، أعد تحميل خدمة PHP الخاصة بالموقع من لوحة الاستضافة. صفحة الإعدادات وزر الصيانة متاحان لدور `admin` فقط. زر الصيانة لا يغني عن تحديث كاش النشر عند إضافة مسارات جديدة لأول مرة.

اضبط PHP `upload_max_filesize=10M` و`post_max_size=12M` على الأقل، وحد الرفع في Nginx/Apache بما يناسب ذلك. المرفقات في `storage/app/private/media` وتفتح عبر مسار يتطلب جلسة وصلاحية وفرعًا؛ **لا تنشئ رابطًا عامًا لهذا المجلد**. الحد 60 مرفقًا لكل طلب. خذ نسخًا احتياطية متزامنة للقاعدة والمرفقات واختبر الاستعادة. لا توجد مهام خلفية إلزامية أو تحويلات صور في هذه النسخة.

السجل يوثق إجراءات التطبيق، وليس نظامًا مستقلًا مقاومًا للتعديل المباشر من مدير قاعدة البيانات. حماية الجلسة وCSRF فعالة، والدخول محدود المحاولات. لا توجد بوابة دفع بنكي: التحويل يسجل مرجعًا ومستند إثبات الدفع.

## الاختبارات

```bash
php artisan test
```

تستخدم الاختبارات SQLite داخل الذاكرة وتخزين مرفقات معزولًا. يغطي الاختبار: دورة الدفع والإغلاق، فصل الفروع والصلاحيات، المرفقات الخاصة، الحماية من التكرار، ذرية المخزون، الاستلام التصحيحي، مرتجعات الصرف، استيراد Excel المتراجع، النصوص الآمنة في التصدير وحسابات العملة. مخطط MySQL جاهز بالترحيلات، لكن الاختبارات المرفقة شُغلت على SQLite، وليس على خادم MySQL. راجع التزامن على بيئة MySQL المستهدفة قبل الإطلاق الفعلي.

راجع `docs/DATABASE.md` للعلاقات و`docs/API.md` للمسارات. ملف `composer.lock` يثبت نسخ الحزم. مجلد `vendor` و`.env` وقواعد البيانات والمرفقات التشغيلية غير مضمنة في الحزمة؛ تُنشأ بخطوات التشغيل.
