# نطاق التحقق

- PHP 8.3.11؛ Laravel 12.69.1؛ SQLite داخل الذاكرة للـ Feature Tests.
- 18 اختبارًا وظيفيًا و80 تحققًا: دورة شراء فعلية، مطابقة وسداد وإغلاق، الصلاحيات ونطاق الفروع، منع الاعتماد الشخصي، الصور التسع، خصوصية المستندات، حماية آخر مدير، المستخدمون والأدوار، حركات المخزون والمرتجعات والتصحيح ومنع التكرار، استيراد Excel وتصديره.
- تحقق HTTP فعلي: تسجيل الدخول بجلسة، لوحة التحكم، الطلبات، الأصول المحلية، تنزيل XLSX؛ طلب تعديل بلا CSRF أعاد 419.
- نجاح `config:cache` و`route:cache` و`view:cache`، وفحص JavaScript نحويًا بـ `node --check`، وتنسيق PHP بـ Laravel Pint.
- لم تُنفذ معاينة متصفح رسومية: Chromium غير متاح وفشل تنزيله في بيئة العمل. يلزم فحص الواجهة والكاميرا على الأجهزة المستهدفة.
- لم يتوفر خادم MySQL للاختبار. الترحيلات متوافقة معه، لكن اختبارات الضغط والتزامن وتهيئة الخادم الإنتاجي تتطلب بيئة النشر.
- ملفات الصور المرجعية وصورة المستند التجريبي مرفقة لأغراض العرض. لا توجد حوالات بنكية حقيقية أو ربط بنظام محاسبي خارجي.
